## 原理：官方中文的问题在于「字库缺字」

官方简体中文的文本翻译是有的，但**字体文件里没有对应的字形**，
于是一部分汉字渲染不出来（空白、方块或问号）。

本补丁扫描全部资源包，统计出界面实际需要的**2510 个可见字符**（其中 **2388 个是汉字**），
再为游戏中用到的**每一个字体**补齐字形，做到**一个都不缺**。

| 项目 | 数值 |
|---|---|
| 扫描资源包 | 146 个 |
| 语言数据库 | 562 个 |
| 需要的可见字符 | 2510 个 |
| 其中汉字 | 2388 个 |
| 补齐后各字体缺字数 | **0** |
| 覆盖字形成员（字体 × 资源包） | **33 个** |

覆盖的字体包括 `pexico_large` / `pexico_medium` / `pexico_small` /
`mojangBitmap_big` / `mojangBitmap_medium` / `mojangBitmap_small` / `mojangBitmap_noFilter` /
`Rockwell` / `Bevan`，横跨 `MCSM_win10_Chinese_all`、`MCSM_win10_Menu_txmesh`、
`MCSM_win10_Project_txmesh`、`MCSM_win10_Win10_108_CHN_compressed` 等资源包。

**覆盖八个章节的字幕与菜单**（菜单字形单独处理，因为菜单用的是另一套资源包）。

**只补字形，不改动原有文字翻译、字体图像、字符间距或其他资源。**
新增字形由 **GNU Unifont 16.0.04** 生成（OFL-1.1），许可与源字形附在包内 `font_source\`。

## 使用方法

1. 完整解压本压缩包，**彻底退出游戏**，保留至少 8 GB 空间。
2. 双击「**一键汉化.cmd**」，选择含 `GameApp.exe` 的第一季游戏目录。
3. 安装完成后手动启动游戏，把语言设为 **English / 英语**。

**还原**：双击「一键还原.cmd」，恢复到首次安装 v1.1 之前的文件状态
（原版安装则还原原版；旧汉化版升级则还原旧汉化版）。
备份位于游戏目录的 `_MCSM1_ZH_Backup_v1.1`，**请勿删除、移动或与另一份游戏混用**。

**检查**：双击「检查版本.cmd」只检查资源兼容性与新版文件状态，不改任何文件。
