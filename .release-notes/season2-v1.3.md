《我的世界：故事模式》第二季 UWP 简体中文补丁（第五章字幕修复）

## 适用版本
- 包标识：`TelltaleGames.MinecraftStoryMode-Season2`
- 包版本：`1.0.6.0`
- 架构：x64

两季各自独立，本包**完整自包含**，无需先安装第一季补丁。

## 本版内容（v1.3）

**第一至四章**沿用 v1.0 内容，未作改动。

**第五章**（`episode 205`）做了两件事：

### A. 把显示成问号的字幕还原成完整中文句子

之前为「不破坏文件结构」只能把句子硬压成短词，例如那四个对话选项：

| | 文本 |
|---|---|
| v1.2（短词版） | 有线索 / 卢卡 / 为何 / 回 |
| **v1.3（完整版）** | 管理者有没有透露什么？ / 卢卡斯在哪里？ / 你们怎么会在这里？ / 我得回去。 |

### B. 修掉了「一改就整章没字幕」的根本原因

Telltale 的 `.landb` 语言文件是 MSV6（MetaStream）格式，正文由一条条「条目」组成，
每条条目头部存着**本条目的长度**。字符串一变长，这个长度必须跟着重算——
此前所有修复脚本都只改了文件头的总长度，条目长度全是旧值，游戏解析到第一条就错位，
整组语言资源被拒绝，表现就是字幕全没、选项显示 `This choice is blank!`。

本版按格式**逐条重算**，并用第四章（同样是「英文变中文」的场景）的 13 个语言文件
做过**逐字节回归验证**。

## 使用方法

1. 完整解压本压缩包，**彻底退出游戏**（任务管理器里确认没有 `GameApp.exe`）。
2. 双击「**一键汉化.cmd**」，选择游戏**根目录**（脚本一般会自动找到；
   手动选时注意**不是** `Archives` 子目录）。
3. 安装完成后手动启动游戏，把语言设为 **English / 英语**。
   > 英语槽位显示中文是本补丁的既定工作方式，**请不要选「简体中文」**。

**还原**：双击「一键还原.cmd」。「检查版本.cmd」只做检查。

## 备份说明

首次安装会把原版资源包备份到游戏根目录的 `_MCSM2_ZH_Backup_v1`，
还原时从那里取。**安装后请不要删除这个备份目录。**

如果之前装过别的汉化又没留原版备份，补丁会**拒绝安装并提示原因**（不会乱改文件）。
这种情况请先从平台重新安装游戏，或先用旧补丁的还原功能。
