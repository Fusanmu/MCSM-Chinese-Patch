## 问题：第五章官方中文的三层缺陷

1. **文本层**：第五章有 **115 处连续问号占位**，句子根本没翻译出来。
2. **格式层**：把问号换成完整中文句子后 → **整章字幕消失**，
   四个对话选项全部显示引擎的英文兜底串 `This choice is blank!`。
   说明整组语言资源被引擎**拒绝加载**。
3. **妥协方案**：改用"等长覆盖"（把句子硬压成短词）→ 字幕能显示，但文字严重残缺。

## 根因

Telltale 的 `.landb` 语言文件是 **MSV6 MetaStream** 格式（魔数 `6VSM`），
正文由一条条「条目（entry）」组成，**每条条目头部都存着本条目的长度**。
字符串一变长，这个长度**必须跟着重算**。

此前所有修复脚本**只更新了文件头的总长度**，所有条目的长度字段还是旧值 →
引擎按旧长度跳读，**解析到第一条就错位** → 整组语言资源被拒绝。

这就是"一改就全章没字幕"的真正原因，也解释了为什么"等长覆盖"能工作
（长度不变，长度字段天然正确）。

> 最隐蔽的一点：**第 0 条条目的长度字段位置恰好落在文件头部区**（偏移 `@220`），
> 看起来像"文件头字段"，所以最容易被漏掉。

## 本版修复

按格式**逐条重算**每一条条目的长度，并同步 `N`（含非 ASCII 即 14）、`@4`、`@156`。

**修复效果**（第五章那四个对话选项）：

|---|---|
| v1.2（短词妥协版） | 有线索 / 卢卡 / 为何 / 回 |
| **v1.3（本版）** | 管理者有没有透露什么？ / 卢卡斯在哪里？ / 你们怎么会在这里？ / 我得回去。 |

## 验证方式

用**第四章**作天然对照组（它的 landb 同样是"英文→中文变长"，而游戏能正常读）。
以"原始文件 + 目标文本 → 重建"的输出与 v1.0 **逐字节比对**：

这证明所用改写规则与原作者一致。归档层面另做了**解包回来 1980 个文件与打包输入逐字节一致**的校验。

## 使用方法

1. 完整解压本压缩包，**彻底退出游戏**（任务管理器里确认没有 `GameApp.exe`）。
2. 双击「**一键汉化.cmd**」，选择游戏**根目录**（脚本一般会自动找到；
   手动选时注意**不是** `Archives` 子目录）。
3. 安装完成后手动启动游戏，把语言设为 **English / 英语**。
   > 英语槽位显示中文是本补丁的既定工作方式，**请不要选「简体中文」**。

**还原**：双击「一键还原.cmd」。「检查版本.cmd」只做检查。

## 备份说明

首次安装会把原版资源包备份到游戏根目录的 `_MCSM2_ZH_Backup_v1`，
还原时从那里取。**安装后请不要删除这个备份目录。**

如果之前装过别的汉化又没留原版备份，补丁会**拒绝安装并提示原因**（不会乱改文件）。
这种情况请先从平台重新安装游戏，或先用旧补丁的还原功能。
