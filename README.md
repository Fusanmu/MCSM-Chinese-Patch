# 《我的世界：故事模式》UWP 简体中文补丁

针对 **Microsoft Store / Xbox App（UWP）版**《我的世界：故事模式》（Minecraft: Story Mode）的简体中文汉化补丁，覆盖**第一季**与**第二季**。

这两套补丁不是简单的"把英文换成中文"——它是在官方简体中文的基础上做了**一系列修复**：
补全官方中文缺失/显示为问号的文本、修复字库缺字、修好让整章字幕消失的格式缺陷。
两季均**已通过实机测试**。

> 本项目只做**本地资源替换**：不改 `GameApp.exe`，不改游戏清单，不改存档，不联网。
> 所有改动都发生在游戏目录的 `Archives\` 目录下。

## 相对官方中文修复了什么

### 第一季 · v1.1 —— 字库补全

**问题**：官方简体中文的文本翻译是有的，但**字体文件里没有对应的字形**，
于是一部分汉字渲染不出来（空白、方块或问号）。

**修复**：扫描全部资源包，统计出界面实际需要的**2510 个可见字符**（其中 **2388 个是汉字**），
再为游戏中用到的**每一个字体**补齐字形，做到**一个都不缺**。

| 项目 | 数值 |
|---|---|
| 扫描资源包 | 146 个 |
| 语言数据库 | 562 个 |
| 需要的可见字符 | 2510 个 |
| 其中汉字 | 2388 个 |
| 补齐后各字体**缺字数** | **0** |

覆盖的字形成员（字体 × 所属资源包）共 **33 个**，包括：

| 资源包 | 字体 |
|---|---|
| `MCSM_win10_Chinese_all.ttarch2` | `pexico_large` / `pexico_medium` / `pexico_small` / `mojangBitmap_big` / `mojangBitmap_medium` / `mojangBitmap_small` / `mojangBitmap_noFilter` / `Rockwell` / `Bevan` |
| `MCSM_win10_Menu_txmesh.ttarch2` | `Rockwell` / `Bevan` |
| `MCSM_win10_Project_txmesh.ttarch2` | 同上各字体 |
| `MCSM_win10_Win10_108_CHN_compressed.ttarch2` | `mojangBitmap_noFilter` / `mojangBitmap_medium` |

**保留原有内容**：只补字形，不改动原有文字翻译、字体图像、字符间距或其他资源。
**新增字形来源**：GNU Unifont 16.0.04（许可与源字形附在包内 `font_source\`）。

**覆盖章节**：八个章节的字幕与**菜单**（菜单字形单独处理，因为菜单用的是另一套资源包）。

### 第二季 · v1.3 —— 第五章字幕与选项修复

**问题**（三层，逐层深入）：

1. **文本层**：官方中文（以及早期 v1.0 补丁）在第五章有 **115 处连续问号占位**，
   句子根本没翻译出来。
2. **格式层**：把问号换成完整中文句子后 → **整章字幕消失**，四个对话选项全部显示
   引擎的英文兜底串 `This choice is blank!`。说明整组语言资源被引擎**拒绝加载**。
3. **妥协方案**：改用"等长覆盖"（把句子硬压成短词）→ 字幕能显示，但文字严重残缺。

**根因**：Telltale 的 `.landb` 语言文件是 **MSV6 MetaStream** 格式（魔数 `6VSM`），
正文由一条条「条目（entry）」组成，**每条条目头部都存着本条目的长度**。
字符串一变长，这个长度**必须跟着重算**。

此前所有修复脚本（`repair_ch5.py`、`build_full_language_archives.py`）**只更新了文件头的总长度**，
所有条目的长度字段还是旧值 → 引擎按旧长度跳读，解析到第一条就错位 →
**整组语言资源被拒绝**。这就是"一改就全章没字幕"的真正原因，
也解释了为什么"等长覆盖"能工作（长度不变，长度字段天然正确）。

> 最隐蔽的一点：**第 0 条条目的长度字段位置恰好落在文件头部区**（偏移 `@220`），
> 看起来像"文件头字段"，所以最容易被漏掉。

**修复**：按格式**逐条重算**每一条条目的长度。

**修复效果对比**（第五章那四个对话选项）：

| | 文本 |
|---|---|
| v1.2（短词妥协版） | 有线索 / 卢卡 / 为何 / 回 |
| **v1.3（本版）** | 管理者有没有透露什么？ / 卢卡斯在哪里？ / 你们怎么会在这里？ / 我得回去。 |

**改动范围**：

| 项目 | 数值 |
|---|---|
| 主包大小变化 | 84,960,381 → 84,962,534 字节（**+2153**，正好等于 14 个语言文件的净增量） |
| 改动的语言文件 | **14 个**（`*_english.landb` 英文槽） |
| 字节级未改动的文件 | **1966 个** |
| 条目自洽校验 | 15 个语言文件、**2256 条条目、0 错误** |

第一至四章沿用 v1.0 内容，**未作改动**（第五章之外的资源包保持原样，见下方清单）。

### 验证方式

- **第一季**：`verification.json` 记录了 146 个资源包 / 562 个语言库的逐字体扫描结果，
  每个字体 `missing` 均为 **0**；安装器另跑了 `clean` 与 `upgrade` 两套场景测试
  （含幂等安装、幂等还原、损坏包拒装、不支持的文件拒装、只读拒装、写入失败回滚），全部通过。
- **第二季**：用**第四章**作天然对照组（它的 landb 同样是"英文→中文变长"，而游戏能正常读）。
  以"原始文件 + 目标文本 → 重建"的输出与 v1.0 逐字节比对：
  **13 个文件里 12 个完全一致**，剩下 1 个（`env_underneathromeotown`）仅 2 字节不同，
  差异位于条目之后的一个小字段（取值 64/72/74，疑似校验/长度提示，与文本长度无稳定关系）。
  这证明所用改写规则与原作者一致。
- **实机测试**：两季补丁均已通过游戏内实测。

## 使用方法（两季通用）

1. **完整解压**压缩包（不要直接在压缩包里双击运行）。
2. **彻底退出游戏**——任务管理器里确认没有 `GameApp.exe` 残留。
3. 双击 **`一键汉化.cmd`**，按提示选择游戏目录：
   - 第一季：选择包含 `GameApp.exe` 的那个目录。
   - 第二季：选择游戏**根目录**（**不是** `Archives` 子目录）。
4. 安装完成后**手动启动游戏**，把游戏语言设为 **English / 英语**。
   > 中文文本放在英语槽位里，这是既定工作方式。**请不要选「简体中文」**——
   > 官方简体中文槽位本身就带有问号缺陷，与本次补丁无关。

**其他脚本：**

- `一键还原.cmd` —— 恢复到安装补丁之前的文件状态。
- `检查版本.cmd` —— 只做兼容性检查，不改任何文件。

## 安装、备份与还原

- **覆盖面**：第一季替换 `Archives\` 下 **33 个** `.ttarch2` 资源包；
  第二季替换 **24 个** `.ttarch2` 资源包。两季都不动 `GameApp.exe`、存档和系统文件，也不联网。
- **备份**：
  - 第一季 → 游戏目录的 `_MCSM1_ZH_Backup_v1.1`
  - 第二季 → 游戏根目录的 `_MCSM2_ZH_Backup_v1`
  **安装后请勿删除、移动该备份目录，也不要与另一份游戏混用。**
- **安全机制**：安装前验证补丁包、备份和准备文件；写入失败会**尝试回滚并报告结果**。
  如果之前装过别的汉化又没留原版备份，补丁会**拒绝安装并提示原因**（不会乱改文件）——
  这种情况请先从平台重新安装游戏，或先用旧补丁的还原功能。
- **还原语义**：恢复到首次安装本补丁**之前**的状态。原版安装则还原原版；旧汉化版升级则还原旧汉化版。

## 兼容性与风险提示

- 补丁以**游戏身份 + 资源文件指纹**判断兼容性。游戏版本与上表不符时请**不要安装**。
- 第二季请保持 `1.0.6.0` 版本，商店更新后补丁可能失效。
- 建议安装前自行备份一次 `Archives\` 目录（安装器也会自动备份，但双保险更好）。
