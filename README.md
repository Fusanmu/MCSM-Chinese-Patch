# 《我的世界：故事模式》UWP 简体中文补丁

针对 **Microsoft Store / Xbox App（UWP）版**《我的世界：故事模式》（Minecraft: Story Mode）的简体中文汉化补丁，覆盖**第一季**与**第二季**。

> 本项目只做**本地资源替换**：不改 `GameApp.exe`，不改游戏清单，不改存档，不联网。
> 所有改动都发生在游戏目录的 `Archives\` 目录下。

## 使用方法（两季通用）

1. **完整解压**压缩包（不要直接在压缩包里双击运行）。
2. **彻底退出游戏**——任务管理器里确认没有 `GameApp.exe` 残留。
3. 双击 **`一键汉化.cmd`**，按提示选择游戏目录：
   - 第一季：选择包含 `GameApp.exe` 的那个目录。
   - 第二季：选择游戏根目录（**不是** `Archives` 子目录）。
4. 安装完成后**手动启动游戏**，把游戏语言设为 **English / 英语**。
   > 这是既定工作方式：中文文本放在英语槽位里。**请不要选「简体中文」**，
   > 简体中文槽位是官方自带的那套，本身就是不完整的。

**其他脚本：**

- `一键还原.cmd` —— 恢复到安装补丁之前的文件状态。
- `检查版本.cmd` —— 只做兼容性检查，不改任何文件。

## 第一季 · v1.1（字库补全）

- **适用**：`TelltaleGames.MinecraftStoryMode-ATelltaleGamesSer`，包版本 `1.11.0.1`，x86。
- **修复内容**：补全八个章节字幕与菜单所需的字形，保留原有文字、字体图像、间距及其他资源。
- **新增字形**来源：GNU Unifont 16.0.04（许可与源字形附在 `font_source\` 内）。
- **还原说明**：备份保存在游戏目录的 `_MCSM1_ZH_Backup_v1.1`。原版安装则还原原版，旧汉化版升级则还原旧汉化版。
  **请勿删除、移动该备份目录，也不要与另一份游戏混用。**

## 第二季 · v1.3（第五章字幕修复）

- **适用**：`TelltaleGames.MinecraftStoryMode-Season2`，包版本 `1.0.6.0`，x64。
- **第一至四章**沿用 v1.0 内容，未作改动。
- **第五章**（`episode 205`）做了两件事：

  **A. 把显示成问号的字幕还原成完整中文句子。**
  之前为「不破坏文件结构」只能把句子硬压成短词，例如那四个对话选项：

  | | 文本 |
  |---|---|
  | v1.2（短词版） | 有线索 / 卢卡 / 为何 / 回 |
  | **v1.3（完整版）** | 管理者有没有透露什么？ / 卢卡斯在哪里？ / 你们怎么会在这里？ / 我得回去。 |

  **B. 修掉了「一改就整章没字幕」的根本原因。**
  Telltale 的 `.landb` 语言文件是 MSV6（MetaStream）格式，正文由一条条「条目」组成，
  每条条目头部存着**本条目的长度**。字符串一变长，这个长度必须跟着重算——
  此前所有修复脚本都只改了文件头的总长度，条目长度全是旧值，游戏解析到第一条就错位，
  整组语言资源被拒绝，表现就是字幕全没、选项显示 `This choice is blank!`。
  本版按格式**逐条重算**，并用第四章（同样是「英文变中文」的场景）的 13 个语言文件
  做过**逐字节回归验证**。

- **备份**：首次安装会把原版资源包备份到游戏根目录 `_MCSM2_ZH_Backup_v1`，还原时从那里取。
  **安装后请不要删除这个备份目录。**
- **已知情况**：
  - 第五章的「简体中文」槽位是游戏自带的官方中文，本身就有一部分问号，与本次补丁无关。
  - 游戏请保持 `1.0.6.0` 版本，商店更新后补丁可能失效。
  - 如果之前装过别的汉化又没留原版备份，补丁会**拒绝安装并提示原因**（不会乱改文件）。
    这种情况请先从平台重新安装游戏。

## 兼容性与风险提示

- 补丁以**游戏身份 + 资源文件指纹**判断兼容性。游戏版本与上表不符时请**不要安装**。
- 安装器会在写入前验证补丁、备份与准备文件；写入失败会尝试回滚并报告结果。
- 建议安装前自行备份一次 `Archives\` 目录。
- 资源覆盖、文件格式、字形图像与安装/升级/还原流程均已做本地检查，
  但仍建议**在游戏中实测**渲染、字体加载与章节切换效果。
