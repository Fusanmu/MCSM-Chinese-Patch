## 一、Telltale `.landb`（MSV6 MetaStream）格式

`.landb` 是 Telltale 引擎的语言数据库文件，魔数 `6VSM`（小端即 `MSV6`）。
文件**正文不是裸字符串**，而是由一条条「条目（entry）」组成：

```
ENTRY := u32 8, u32 0, u32 0, u32 SIZE, BLOCK+, u32 8, u32 N, u32 8
BLOCK := u32 total, u32 len, len 字节 UTF-8 文本        (total == len + 8，len 可为 0)

SIZE  == sum(BLOCK.total) + 12
N     == 14（已本地化为中文）/ 1（未翻译）
```

### 头部随内容变化的字段

| 偏移 | 含义 | 变化规则 |
|---|---|---|
| `@4` | 正文总大小 | `+= 总增量` |
| `@156` | 恒等于 `@4 - 52` | `+= 总增量` |
| `@220` | **第 0 条条目的 SIZE** | 它就是第 0 条条目的长度字段，位置恰好落在头部区内 |

### 关键点

**每一条条目的 `SIZE` 字段都必须随其内部字符串长度重算**，
它位于该条目内部第一个字符串块之前 16 字节处（即 `prefix + 12`）。

第 0 条条目的 `SIZE` 因为紧邻头部区，看起来像"头部字段 `@220`"，
**所以最容易被漏掉**——这正是此前修复全部失败的原因。

## 二、第二季第五章：为什么"一改就整章没字幕"

### 现象

1. 第五章部分字幕显示为问号占位（v1.0 补丁自带，**115 处连续问号**）。
2. 把这些问号换成完整中文句子后 → **字幕整体消失**，对话选项全部显示
   `This choice is blank!`（引擎的英文兜底串）→ 说明**整组语言资源被引擎拒绝**。
3. 退而求其次用"等长覆盖"（把句子压成"有线索/卢卡/为何/回"这种短词）→
   字幕正常，但文字明显残缺。

### 根因

之前的修复脚本（`repair_ch5.py` / `build_full_language_archives.py`）
**只更新了 `@4`（正文总大小）**，所有条目的 `SIZE` 都是旧值。

→ 引擎按旧长度跳读，**解析到第一条就错位** → 整组资源被拒。

这也解释了为什么"等长覆盖"能工作：长度没变，`SIZE` 天然正确。

### 修复

按格式**逐条重算 `SIZE`**，并同步 `N`（含非 ASCII 即 14）、`@4`、`@156`。

## 三、验证方法

### 第二季：第四章作天然对照组

第四章（`204`）的 landb **同样是"英文→中文变长"**，而游戏能正常读取 ——
所以它是一个现成的正确答案。

用 `_MCSM2_ZH_Backup_v1` 里打补丁前的原始文件 + 补丁后的 v1.0 文件做
"原始 + 目标文本 → 重建"，与 v1.0 输出**逐字节比对**：

| 结果 | 数量 |
|---|---|
| 逐字节完全一致 | 12 / 13 |
| 仅 2 字节不同 | 1（`env_underneathromeotown`） |

那 2 字节的差异位置在条目**之后**的一个小字段（取值 64 / 72 / 74 区间，
疑似校验/长度提示，**与条目文本长度无稳定关系**），未影响本次修复。

> 这证明了"文本 + 条目 `SIZE` + `N` + `@4` + `@156`"这套改写规则就是原作者使用的规则。

### 第二季：归档级校验

1. 结构基线用 v1.0 原始包解包目录 `full_oldpatch205`（**1980 个文件**，与 `patch205e` 一致）。
2. 英文槽 **15 个** `*_english.landb` 用新的 `landb.py` 按条目重写：
   - 文本取自最终中文（v1.0 已翻好的保留；14 处原为问号的按英文原文补译）。
   - 逐条重算 `SIZE`；`N` 按"含非 ASCII 即 14"设置。
3. 用 `ttarchext -b 63` 重建主包（不含 `0.ttarch2` 覆盖包）。
4. 归档校验：**解包回来 1980 个文件与打包输入逐字节一致**；
   与原始 v1.0 包相比只有 **14 个文件变化**（`towerofficetwisted` 净增量为 0）。

| 项目 | 结果 |
|---|---|
| 主包大小 | 84,960,381 → 84,962,534 字节（**+2153**） |
| 净增量校验 | +2153 == 14 个语言文件的净增量之和 ✓ |
| 未改动文件 | 其余 **1966 个**字节级未变 |
| 条目自洽性 | 15 个语言文件、**2256 条条目、0 错误** |

## 六、回滚

1. 补丁包自带 `一键还原.cmd`（恢复到首次安装前的状态）。
2. 安装器自动备份：
   - 第一季 → `_MCSM1_ZH_Backup_v1.1`
   - 第二季 → `_MCSM2_ZH_Backup_v1`
3. 手动兜底：把备份目录里的 `.ttarch2` 拷回游戏 `Archives\` 即可。
